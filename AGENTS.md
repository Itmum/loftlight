# Loftlight — agent notes

## Stack
- Next.js 16.4.6 App Router (app lives in `src/app`), React 19.3, strict TypeScript, Turbopack bundler.
- `next.config.ts` enables `reactCompiler` — don't add defensive `useMemo`/`useCallback`. `cacheComponents`/`partialPrefetching` are currently **disabled** by the user; if re-enabled, async Server Components need Suspense boundaries and `partialPrefetching` requires `cacheComponents`.
- `partialPrefetching: true` in `next.config.ts` requires `cacheComponents: true` — remove/keep them together, or `next dev` crashes at startup (`partialPrefetching requires cacheComponents`).
- `next dev` auto-restarts when `next.config.ts` changes, so a bad config kills the running server mid-session — check the dev-server log when pages suddenly 500/exit.
- Tailwind v4 with **no config file**: theme is CSS variables in `src/app/globals.css`, loaded via a Turbopack rule in `next.config.ts`. Design tokens (light/dark): background `#FAF5EC`/`#16110E`, card `#FFFDF8`/`#211A16`, terracotta `--primary` `#C8553D`/`#E27A5F`, plus `--sage` and `--mustard` accents. Fonts: Fraunces (`font-serif`, headings) and Inter (`font-sans`, body), loaded via `next/font` in `layout.tsx` and mapped through `@theme inline`.
- Dark mode: `next-themes` with `attribute="class"` (`.dark`), `defaultTheme="system"`.

## shadcn/ui — Base UI, not Radix
- Style `base-nova` (`components.json`); primitives import from `@base-ui/react/*`. Never substitute Radix imports — the API differs.
- To render a `Button` as a link, use Base UI's `render` prop, not `asChild`: `<Button render={<Link href="..." />} nativeButton={false}>`. `nativeButton={false}` is required when the rendered element is not a native `<button>`.
- `cn` is the standalone `cn` package (tailwind-merge based), re-exported at `@/lib/utils`. Aliases: `@/components`, `@/components/ui`, `@/hooks`, `@/lib`.
- `ui/button.tsx` was hand-edited so **all** button variants render as pills (`rounded-full`). A future `shadcn add/update button` will overwrite this.
- UI copy panels/cards: one card style everywhere — `bg-card` + `text-card-foreground` + `text-muted-foreground`, `rounded-3xl`.
- This lucide-react build (1.72.0) has **no brand icons** (no Twitter/Instagram/Youtube) — social icons are inline SVGs.
- Reuse `src/components/link-button.tsx` (`LinkButton`: shadcn Button rendered as a Next Link) and `src/components/site-logo.tsx` (`SiteLogo`, shared by navbar/footer) instead of re-rolling them.

## Backend API
- Pages fetch a separate backend at `http://localhost:8000` (e.g. `GET /all-studios`), overridable via `NEXT_PUBLIC_API_URL`. It must be running for those pages to load data.
- Under `cacheComponents`, an uncached `await fetch()` in a Server Component must sit inside a `<Suspense>` boundary — otherwise the route fails prerendering with "Next.js encountered uncached data during prerendering".

## Verification
- `npm run dev` / `npm run build` / `npm run lint` (flat ESLint config).
- Typecheck: `npx tsc --noEmit` — there is no script for it.
- No tests configured.
- A long-running `next dev` process can keep serving stale content after file edits (observed in practice). If the running app doesn't match the source: kill the dev server, delete `.next`, restart `npm run dev`.
- Clearing `.next` breaks `npx tsc --noEmit` until the generated types return: `LayoutProps` lives in `.next/types/**` (regenerated by `npm run build` or `dev`). Run one of those before typechecking.
- Using `next-themes` requires `suppressHydrationWarning` on `<html>` in `layout.tsx` — its script sets `class`/`color-scheme` before hydration and otherwise triggers hydration mismatch errors.
- `npm run lint` currently fails with 2 pre-existing `react-hooks/set-state-in-effect` errors in shadcn-generated `src/components/ui/carousel.tsx` and `src/hooks/use-mobile.ts`. Don't chase them; just confirm your own files add no new ones.
